# IDA ICE Shaded Simulation Models

This folder contains the IDA ICE models used for the partial-shading simulations of Systems A, B, and C (RISE Systems 3, 8, and 9).

The models include the near-field shading objects used in the experimental shading study: pole-type obstructions for Systems A and C and a nearby tent obstruction for System B.

The `Weather_IDA_shaded` folder contains the weather files used for the shaded simulation period. As for the annual simulations, the System 3 weather data are used for System A, while the System 9 weather data are used for both Systems B and C.
