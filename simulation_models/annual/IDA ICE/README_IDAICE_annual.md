# IDA ICE Annual Simulation Models

This folder contains the IDA ICE models used for the annual, unshaded simulations of Systems A, B, and C (RISE Systems 3, 8, and 9).

The `Weather_IDA_annual` folder contains the annual IDA ICE weather files generated using both the Engerer2 (E2) and Perez–Driesse (PD) irradiance separation methods. The Perez–Driesse weather files were used for the final analysis.

Two weather datasets are used because irradiance and temperature measurements were available from two locations at the RISE test site:

- `System3` weather file → used for **System A (RISE System 3)**
- `System9` weather file → used for **both System B (RISE System 8) and System C (RISE System 9)**

Systems B and C use the same weather file because they are located next to each other at the test site.
