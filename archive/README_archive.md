# pv-validation-idaice-pvsyst
Reproducible data-processing, validation, uncertainty, sensitivity, and figure-generation workflow for comparing PV simulations in IDA ICE and PVsyst against measured data.
# Archive

This directory contains superseded, historical, or development-stage analysis material retained for provenance.

Files stored here are **not part of the active manuscript reproduction workflow**.

---

## Purpose

The analysis developed through several stages before the final reproducible workflow was established.

Earlier scripts and intermediate methods are retained where they help document:

- how the analysis evolved;
- which approaches were superseded;
- why later methodological decisions were made;
- how earlier figures or calculations differed from the final analysis.

Keeping these files separate prevents historical code from being confused with the active analysis while preserving the development record.

## Superseded irradiance analyses

Earlier stages of the study included simulation and analysis files based on different irradiance reconstruction methods and intermediate preprocessing approaches.

The final manuscript uses:

```text
Perez–Driesse
```

as the primary irradiance-reconstruction case.

Engerer2 is retained in the active workflow as a documented sensitivity analysis.

Older Engerer2 calculations or mixed-provenance intermediate files should not be substituted for the final sensitivity datasets generated by:

```text
scripts/07_reverse_transposition_sensitivity.py
```

---

## Superseded solar-geometry calculations

Earlier versions of the weather-condition analysis used a simplified incidence-angle calculation.

That implementation was superseded by the final full azimuth-dependent solar-geometry calculation.

The final analysis uses:

- physical timestamps;
- solar position calculated for the Borås site;
- full surface azimuth and tilt;
- azimuth-dependent angle of incidence;
- extraterrestrial irradiance projected onto the tilted plane.

The final weather-condition results and Figure 3 should therefore be generated only from the active workflow.

Older weather-bin figures or tables retained in the archive are not authoritative.

## Reproducibility

A reader attempting to reproduce the published study should begin with:

```bash
python scripts/00_check_inputs.py
```

and then follow:

```text
docs/REPRODUCIBILITY.md
```

No file in this archive is required to reproduce the final published analysis unless explicitly stated elsewhere in the repository documentation.

The archive should therefore not be added to the normal script execution path.

---

## Editing policy

Archived files should generally not be modified simply to make them compatible with the current workflow.

If a historical script needs to be restored or reused:

1. copy it into an appropriate active-development location;
2. document why it is being restored;
3. update it separately;
4. test it against the current repository structure;
5. do not silently overwrite the archived version.

The purpose of this directory is to preserve historical provenance rather than maintain executable current code.

---

## Interpretation

The presence of a method, script, figure, or result in this archive does not imply that it was used in the final manuscript.

When an archived result differs from an active result, the active scripted workflow takes precedence.

Questions about why an analysis was superseded should be resolved using:

```text
docs/DATA_PROVENANCE.md
docs/METHODS.md
docs/KNOWN_LIMITATIONS.md
scripts/audits/
```

together with the Git commit history where appropriate.
